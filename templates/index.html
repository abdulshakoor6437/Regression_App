REST API Specifications

Seamless JSON endpoints for integrating predictions into any external client

1. Predict Insurance Charges

Endpoint: POST /api/predict/insurance

curl -X POST http://127.0.0.1:5000/api/predict/insurance \
  -H "Content-Type: application/json" \
  -d '{
    "age": 30,
    "sex": "male",
    "bmi": 25.0,
    "children": 0,
    "smoker": "no",
    "region": "southwest"
  }'
